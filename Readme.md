# Anurag Srivastava — Portfolio Website

## Project Overview
A personal portfolio landing page built with plain HTML, CSS, and JavaScript. This website showcases Anurag Srivastava as a Full Stack Developer with MERN, Java Spring Boot, and frontend expertise.

## Key Features
- Responsive one-page portfolio layout
- Custom animated cursor and glowing background orbs
- Interactive terminal-style hero section with typed content
- Smooth scroll navigation to page sections
- Scroll reveal animations for cards and sections
- Skill progress bars that animate on scroll
- Clean dark theme with neon accents and gradient highlights

## Files Included
- `anurag-portfolio.html` — main portfolio page
- `style.css` — styles, layout, animations, and responsive design
- `javascript.js` — custom cursor movement, scroll reveal, smooth scrolling, and interaction logic
- `Readme.md` — this detailed project description

## Sections
- **Hero** — name, roles, summary, portfolio and contact buttons, terminal mockup, and experience stats
- **Tech Stack** — frontend, backend, Java, database, DevOps, and design tools
- **Architecture** — Java full stack system architecture diagram
- **Skills** — skill proficiency bars for MERN and Java stack technologies

## How to Run Locally
1. Open `anurag-portfolio.html` directly in your browser.
2. Or open a local server from the project folder and navigate to `http://localhost:PORT`.

Example using Python:
```bash
python -m http.server 8000
```

## Customization
- Update the hero text, name, role tags, and contact email in `anurag-portfolio.html`
- Change the tech stack items and badges in `anurag-portfolio.html`
- Modify colors, layout, and animation speed in `style.css`
- Add new interactive behavior or section transitions in `javascript.js`

## Notes
- This is a static frontend portfolio with no backend dependencies.
- The site uses Google Fonts (`JetBrains Mono` and `Syne`).
- The `javascript.js` file currently enables a custom cursor, scroll reveal animations, and smooth section navigation.
